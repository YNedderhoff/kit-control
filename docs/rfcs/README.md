# Requests for comments

Use the [documentation lifecycle](../../CONTRIBUTING.md#documentation-lifecycle) for proposal scope, statuses and decision links. No open RFC is currently recorded.

Existing accepted choices are in [ADRs](../adrs/README.md); their implementation remains in the [editor project](../projects/2026-10-25-kitcontrol-editor.md). Do not invent a retrospective proposal process or treat an implementation gap or unknown device fact as a new architecture decision. Create a scoped RFC when there is an actual proposal or unresolved tradeoff to decide.
